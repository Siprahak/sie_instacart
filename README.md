# SIE Instacart – Executive Dashboard
Next.js 14 + TypeScript + Tailwind CSS + Apache ECharts.

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

Data: `public/dashboard_data.json` (hasil `clean_instacart.py`). Ganti file ini jika data diperbarui.
Deploy gratis: push ke GitHub lalu import di vercel.com.
